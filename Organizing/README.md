# Organizing Skills

This acts as an index directory to the resources available to develop skills
for organizing peer-mentoring groups.


- **[Shared Responsibility](shared-responsibility.md)**: Members of a peer-mentoring group own a shared
  responsibility for the existence of the group. Everyone needs to (learn to)
  step up and accept that responsibility.
