# Properties

This acts as an index directory to the resources available to address certain
properties relevant for organizing peer-mentoring groups. For each property,
there should be a fact-sheet describing its objective, intention and rationale;
and/or Observation, Effect, Need, Request.



- **Communication Channel**: Group members should agree on a simple and
  accessible communication channel. Members should be either be able to
  self-manage their contact information, or someone should step up and take --
  temporary -- responsibility through the Decision-Making Process to manage
  them.

- **Findability**: People new to a field have a hard time connecting to fellow
  practitioners.

- **Frequency**: The length of the interval between meetings does matter.
  Weekly seems too short, so that people skip sessions. Whereas monthly seems
  too long, so that people do not feel committed; especially if one session has
  to be skipped due to holidays. **Bi-weekly seems to be the sweet spot**.
