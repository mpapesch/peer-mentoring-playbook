# Meta-Information Template

This Playbook is a collection of resources to prevent, address, solve, and/or
overcome problems encountered when running a peer-mentoring group.

- **Name or Identifier**: Each resource needs a unique name or Identifier by
  which it can be referenced.

- **Problem**: A description of the problem that is to be addressed and its
  negative consequences.

- **Objective**: A concise statement of the desired outcome of applying the
  resource.

- **Approach**: A description of _how_ the resource may be applied to achieve
  the objective.

- **Further Resources**: References and links to further resources providing
  more detailed or additional background information.
